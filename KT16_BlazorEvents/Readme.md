## КТ №16 Обработка событий
Задачи:
Выполнить задание из презентации (пример);
Выполнить задание по ТЗ (варианты ниже);
Оформить отчет со скриншотами и ссылками на код.

Часть 1. Форма ввода
Создайте новый компонент FormComponent.razor, который будет содержать форму с полями для ввода имени, возраста и выбора пола (мужской/женский).
Обработайте события ввода для каждого поля и отобразите введенные данные ниже формы.
Добавьте кнопку для сброса всех полей формы к начальным значениям.
Используйте созданный компонент на главной странице вашего Blazor-приложения.

Часть 2. Форма обратной связи
Разработайте компонент FeedbackForm.razor, который содержит форму обратной связи с полями: имя пользователя, email и текст сообщения.
Реализуйте валидацию полей формы с помощью событий ввода (@oninput) и уведомляйте пользователя об ошибках в режиме реального времени.
При нажатии кнопки "Отправить" данные формы должны сохраняться в локальную переменную, а затем отображаться в компоненте.
Добавьте кнопку "Очистить", которая сбрасывает все поля формы при нажатии.
Отобразите сообщение "Форма отправлена!" при успешном заполнении всех полей.
(Опционально) Добавьте капчу.
